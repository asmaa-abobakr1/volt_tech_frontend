Volt Tech – Frontend

A modern and responsive e-commerce frontend built with React.js and Vite. The application provides an interactive shopping experience, allowing customers to explore products, manage their shopping cart, and interact with the store’s features through a user-friendly interface.

✨ Features

* Responsive and user-friendly interface.
* Product browsing and product details.
* Shopping cart management.
* Product comparison.

* Integration with backend REST APIs.
* Dynamic data rendering.

⚙️ Installation

git clone https://github.com/asmaa-abobakr1/volt_tech_frontend.git
cd volt_tech_frontend
npm install
npm run dev

🔌 Backend Integration

The frontend communicates with the Volt Tech backend through REST APIs to retrieve and manage application data.

Configure the backend API URL in the appropriate environment configuration.
